# Features Overview

`security-review` offers comprehensive policy-driven, offline-first security scanning capabilities for Go repositories.

## Key Capabilities

- **Scan Execution & Policy**: Full, changed, and staged discovery with index isolation and custom fail thresholds.
- **Reports & Finding Lifecycle**: Terminal, JSON, SARIF, and JUnit output with baselines and suppressions.
- **Developer Workflow**: Git hooks integration, local cache management, dry-run fixes, and rule explanations.
- **Client & Frontend Scanning**: Framework detection, client/server/shared classification, threat boundaries, and native rules.
