# Getting Started

Follow the shortest path from installation to a successful scan. These pages are
for developers and CI owners evaluating Go Code Scanner for the first time.

| Step | For | Outcome | Typical time |
| :--- | :--- | :--- | :---: |
| **[1. Installation](/getting-started/installation)** | Developers installing the CLI locally | A working `security-review` binary whose version can be printed. | 2–5 min |
| **[2. First Scan & Exit Codes](/getting-started/first-scan)** | Developers scanning a repository for the first time | A terminal summary, JSON report, and a clear understanding of local versus CI exit behavior. | 5 min |
| **[3. Five-Minute CI Setup](/getting-started/ci-setup)** | Repository and CI maintainers | A repeatable pull-request scan with an enforced severity threshold. | 5–10 min |

Start with [Installation](/getting-started/installation). If the binary already
works, continue directly to [First Scan & Exit Codes](/getting-started/first-scan).

For architecture and behavior rather than setup steps, use the
[Concepts section](/concepts/). For exact flags and fields, use
[Reference](/reference/).
